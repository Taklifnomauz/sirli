MAGIC NAME — Link Generator version

How to use:
1. Upload index.html to the same GitHub Pages repository, replacing the previous index.html.
2. Open your site and press LINK YARATISH.
3. Enter the recipient's name and personal message.
4. Choose NUQTALAR or ASCII, then press HAVOLA YARATISH.
5. Copy the generated URL and send it to that person.

Each link stores its own name/message/mode in URL parameters. You only publish the site once; you do not need a separate GitHub repository for each person.

Note: the URL generator uses the public URL where this page is hosted. Test it after GitHub Pages is enabled.
